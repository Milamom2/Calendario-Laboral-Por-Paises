# Calendario Laboral Por Países

Proyecto académico desarrollado en Spring Boot para gestionar calendarios laborales por país.

## Tecnologías
- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

## Funcionalidades
- CRUD de Países
- CRUD de Tipos de Festivo
- CRUD de Festivos
- Cálculo de Domingo de Pascua
- Validación de si una fecha es festiva
- Listado de festivos por país y año
- Generación del calendario anual
